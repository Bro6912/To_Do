How to Use

Adjusting Parameters

Type values into the input fields on the left. Press Apply Changes to update your timer defaults. Adjusting values mid-session will stop the current countdown.

Interval Cycles

The Long Break Interval dictates how many standard Work Sessions you run before earning a prolonged rest phase (e.g., 4 intervals).

Dashboard Controls

  • Start: Commences the runtime countdown tracking stream.
  • Pause: Temporarily freezes countdown progression.
  • Reset: Restores current countdown mode to its defined default time template.
