# Pomodoro Timer

A simple Pomodoro timer website using HTML, CSS, and JavaScript.

## Get Started

1. Open `index.html` in your browser.
2. Change the timer values in the left panel if needed.
3. Click **Apply Changes**.
4. Use **Start**, **Pause**, and **Reset** to control the timer.

## Files Used in this project:

- `index.html` - page structure and content
- `style.css` - styling and responsive layout
- `script.js` - timer behavior and controls

## Notes

- The theme toggle saves the theme in `localStorage`.
- Audio alerts play when a session ends if enabled.
